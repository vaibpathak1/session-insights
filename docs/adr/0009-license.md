# ADR-0009: Apache License 2.0

**Status:** Accepted · 2026-09

## Decision
Apache 2.0: permissive, patent grant, enterprise-friendly. Every dependency must be
compatible (no AGPL/SSPL/BSL in the default distribution). This ruled out MinIO
(ADR-0003) and TimescaleDB's licensed features (ADR-0002).

The official license text is in the repository root `LICENSE` file.
